# Hikari public hub

Build a public GitHub Pages bot hub with an original Blender moon-cat diorama,
an invite flow, searchable command catalogue, setup guide, and privacy details.
The user explicitly chose a public bot repository and a public information hub.
Live Discord server administration and sign-in are outside this site.

Use ivory surfaces, a plum sidebar, lavender actions, original line icons,
responsive layouts, visible keyboard focus, and reduced-motion support. Include
real command data, no fabricated live metrics, and no private guild/user data.
Bot installation uses Hikari's verified public application ID and guild-only
OAuth scopes. Repository visibility changes only after the public source and
site have been checked for credentials and private runtime files.

The website is static under `site/`; only that directory is deployed by Pages.
Blender generates a local poster, GLB, and editable source. Interactive 3D loads
on demand with an accessible image fallback. Restore the source button in
Discord and link the README to the public invite, source, and dashboard.
