SERVER SETUP

Make room for Hikari.

Invite the bot, choose your channels, and set your club preferences. Manage server settings inside Discord.

01

Invite Hikari

You’ll need Manage Server permission. Review the requested bot permissions in Discord; Administrator is not requested.

Add to Discord
02

Configure the basics

Run /configwizard. Place Hikari above the roles it should manage, and allow it to view and send messages in your anime channels.

03

Choose your club settings

Use /anime admin for channels, spoiler rules, and optional conversation starters. Scheduled starters are off in new servers.

04

Start your first activity

Find a show with /anime discover search and plan a night with /anime club party. Start a private watchlist with /anime list add.

You control the permissions.

The invite includes permissions for moderation, role menus, channels, threads, and voice. Your channel overrides still apply.

Staff commands also check the member’s permissions.

PRIVACY & CARE

Your list. Your choice.

See what stays private, what your club can see, and how to manage your data.

01 / VISIBILITY

Private by default

Watchlists, ratings, and episode notes start private. Club parties, discussions, polls, and anything you deliberately post in a channel are visible to people with access.

02 / YOUR CONTROLS

Sharing and data

Use /anime list privacy for sharing choices, /anime list export to export data, and /anime list delete for deletion. Member comparisons require consent.

03 / THIS WEBSITE

A public bot hub

This site contains public command descriptions and original artwork. It has no Discord sign-in, server management access, personal watchlists, or live member data.

04 / THE BOT

Records and support

The bot stores records needed for chosen features: Discord IDs, preferences, lists, reminders, and moderation records. Contact your server staff or report a code issue without including private data.

Anime discovery and schedules depend on third-party providers. This site is hosted on GitHub Pages. Fonts load from Google Fonts; the optional 3D viewer loads from Google’s library CDN. Hikari adds no analytics or tracking scripts.
